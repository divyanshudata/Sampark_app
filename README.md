
# 📡 Sampark

> **An Offline Communication Application using Mesh Networking**

Communicate anytime, anywhere — even without an internet connection.

🏆 **Built during HackXSprint Hackathon** as a solution for the **Open Innovation** problem statement.  
The project was later evolved and integrated into our larger **AIthon** project.

---

## 📖 Overview

**Sampark** is an offline communication application that enables users to exchange messages without internet connectivity. It leverages **mesh networking** concepts to establish device-to-device communication, allowing nearby devices to connect directly and relay messages across the network.

Designed for emergency situations, rural areas, and network outages, Sampark allows seamless communication without relying on traditional internet or cellular infrastructure.

---

## ❗ Problem Statement

This project was developed for the **Open Innovation** problem statement during the **HackXSprint Hackathon**.

In many real-world scenarios such as:

- 🌪️ Natural disasters
- 🏔️ Remote or rural regions
- 📵 Internet or cellular network failures
- 🚨 Emergency response situations

traditional messaging applications become unusable because they depend on an active internet connection.

**Sampark** solves this challenge by enabling direct offline communication through mesh networking, ensuring people stay connected even when conventional networks fail.

---

## 💡 Solution

Sampark creates a local mesh network where nearby devices communicate directly and relay messages between one another.

Instead of requiring internet access, every connected device acts as a relay node, extending communication range and improving message delivery across the network.
